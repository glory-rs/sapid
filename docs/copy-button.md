# CopyButton and explicit clipboard writes

`copy_button().source(source)` is an intrinsic Button. It submits the currently accepted canonical text through `Scope::copy_text`; an activation is not a success notification. `on_result` receives `ClipboardOutcome::{Written, Denied, Unavailable, Failed}` before generic Clipboard observers. `state_ref` is an output Cage containing `CopyState`, including Idle and Pending. Pending sets typed `aria-busy`; repeated activation while pending creates no additional write.

Text accepts at most 65,536 UTF-8 bytes before cloning, normalizes CRLF/CR to LF and NUL to U+FFFD, and never changes the application's source. Changed accepted text advances a checked revision. Invalid updates retain the previous declaration and produce a typed error. Source updates cancel current result acceptance and feedback without invoking result callbacks. An application cannot dispatch a forged Clipboard completion through `App::dispatch`.

Each live semantic node retains only its numeric request watermark and at most one current pending request. Requests must strictly advance without wrapping; source cancellation does not reset the watermark. The Web host admits at most one non-abortable platform write per document. A later request while that platform operation remains unsettled gets Failed, rather than creating a growing queue of Promises. Retirement and source replacement withdraw acceptance; they cannot undo an OS write which has already begun. Late, duplicate and unknown completions cannot report success for another source or node lifetime.

`feedback_delay(|| Box::pin(host_timer()))` supplies a host timer. One Owner-owned task resets terminal feedback to Idle. A new request, changed source or Owner disposal cancels it. Without this explicit timer terminal feedback remains visible until a new request or source update. The component owns no ambient clock, browser timer or platform thread. `copied_label`, `failed_label`, `label`, four themes, size, explicit styles and `unstyled` customize the actual button.

The source declaration is semantic host data, not a DOM attribute. HTML full shaping, field lowering and the classic stream emit no source edits or plaintext clipboard data. SSR records the ordinary button and interest but rejects the physical action. Native currently advertises no text clipboard driver: a CopyButton activation reports Unavailable, and direct `CopyText` returns typed Unsupported after identity, enabled/inert, source and revision checks. No native OS clipboard support is implied.

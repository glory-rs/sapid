Field

A complete foundation for accessible forms. Compose labels, descriptions, errors and controls with consistent spacing and meaningful states.

New in 0.1InputsWeb · SSR · Native
DocumentationAPI referenceView SSR example ↗

Usage

Give every control a visible label. Add helpful descriptions, validation feedback and required indicators without rebuilding the input.

field("email") .label("Email address") .description("We will only send important account updates.") .required(true) .control(|context| text_field().field(context))
Built on real semantics. Labels activate their associated controls. Read-only fields remain focusable, and a disabled Fieldset protects all controls inside it.

Designed as a system

Blue and green palettes, each with a light and dark scheme. Neutral surfaces, readable text, distinct focus rings and consistent error colors keep every state intentional.

Field API

PropertyPurpose

input_group().start / input / endOrdered text addons and native button sections
theme / size / unstyledPortable appearance with explicit overrides
